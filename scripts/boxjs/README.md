# 📦 BoxJS 蔚来看板订阅使用指南

通过在 BoxJS 中添加 YumikoToys 专属订阅，可以在 BoxJS 的应用列表中直观管理、查看与复制捕获到的蔚来车况凭证、Token 与 4 轮胎压配置。

---

## 🔗 BoxJS 订阅链接
```text
https://raw.githubusercontent.com/kissggj123/NIO-Dash-iOS/main/scripts/boxjs/yumikotoys.boxjs.json
```

---

## 🛠️ 添加步骤（只需添加一次）

1. 在手机 Safari 中打开 **BoxJS**（通常为 `http://boxjs.com` 或 `http://boxjs.net`）；
2. 点击底部导航栏的 **「订阅」**（或「应用」页面右上角的 **+** 订阅管理）；
3. 点击右上角 **「+」** 加号添加新订阅；
4. 粘贴上方的订阅链接，点击 **保存**；
5. 回到 **「应用」** 列表，即可看到 **🐰 蔚来看板 (YumikoToys / YumikoToysRR)** 应用卡片！

---

## 🚗 数据联动

1. 开启小火箭并确保启用了车况抓包模块；
2. 在手机 **蔚来 App** -> 进入 **「爱车」** 页面 -> **【下拉刷新一次】**；
3. 打开 **BoxJS**，刷新页面即可看到：
   - **全量车况 JSON 配置** 已自动填充并格式化好；
   - **Token**、**Vehicle ID**、**Device ID** 与 **车辆全量 RVS URL** 实时同步显示；
4. 点击 **一键复制**，直接回到 **YumikoToys App** 设置点击 **「📋 剪贴板读取并识别」** 即可！
